# AI Психолог — инструкция по запуску

## Что нужно сделать

1. **Сделайте форк репозитория** (или скачайте архив) и разместите папки проекта у себя на компьютере.
2. **Откройте Docker Desktop** — дождитесь, пока он полностью запустится (зелёная иконка).
3. **Откройте терминал** (командную строку, PowerShell или bash) и перейдите в корневую папку проекта (где лежит `docker-compose.yaml`).
4. **Выполните команду**:
   ```bash
   docker-compose up --build
Подождите — Docker соберёт образ и запустит контейнеры. Это может занять некоторое время.

Теперь проект доступен по адресу: http://localhost:8080/

Если нужны переменные окружения
В папке проекта есть файл .env.example. Скопируйте его в .env:

   ```bash
cp .env.example .env        # Linux/macOS
copy .env.example .env      # Windows (cmd)
